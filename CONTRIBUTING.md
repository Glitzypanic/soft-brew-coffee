# Contribuir

1. Abrir un issue con el problema observado o la mejora propuesta.
2. Trabajar en una rama y conservar la identidad visual y el alcance del brief.
3. Ejecutar `npm ci`, instalar Chromium con `npx playwright install chromium` y ejecutar `npm run verify`.
4. En cambios visuales, incluir capturas de escritorio y móvil en la pull request.
5. Describir el comportamiento anterior, el resultado y las comprobaciones realizadas.

No añadir claves, archivos `.env`, dependencias generadas o resultados de pruebas. Evitar cambiar datos de producto, fotografías originales o marca sin confirmación del responsable. Las propuestas no deben añadir compras, formularios o integraciones fuera del alcance acordado.
